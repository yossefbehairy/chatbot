# 🤖 بوت واتساب بالذكاء الاصطناعي

بوت بيرد على رسايل واتساب بشكل طبيعي زي إنسان حقيقي. بيعتمد على **Groq** كمزوّد أساسي و**Google Gemini** كبديل تلقائي، مع ذاكرة محادثة لكل رقم ولوحة تحكم ويب محلية.

> :uk: النسخة الإنجليزية: [README.md](README.md)

---

## ✨ المميزات

- **ردود طبيعية** بلهجة قريبة منك — الشخصية بتتظبط من `SYSTEM_PROMPT` في `config.js`
- **مزوّدان للذكاء الاصطناعي** — Groq أساسي، ولو فشل بيحوّل على Gemini تلقائيًا (بيعمل لو مفتاح واحد بس موجود)
- **ذاكرة لكل جهة اتصال** — تاريخ المحادثات بتتحفظ في `data/memory.json` وبتفضل موجودة بعد إعادة التشغيل
- **لوحة تحكم ويب** على `http://localhost:3750` — تشغيل/إيقاف، أرقام مسموحة، ردود سريعة، فلتر Spam، وإحصائيات
- **أوامر من واتساب** — `/clear` و `/help` و `/mode free` و `/mode triggers`
- **إدارة الجروبات** — رد حر أو على كلمات مفتاحية بس، مع كولداون ساعة لكل جروب عشان ميبقاش Spam
- **فلتر Spam** — حد أدنى لطول الرسالة + حظر الروابط (اختياري)
- **محاكاة الكتابة** — تأخير واقعي قبل كل رد

## 📁 بنية المشروع

```
whatsapp-bot/
├── bot.js                # عميل واتساب + توجيه الرسايل + سيرفر لوحة التحكم
├── ai.js                 # توليد الردود (Groq + Gemini) + ذاكرة المحادثات
├── config.js             # الشخصية وإعدادات الموديل  ← عدّل هنا
├── utils.js              # الإحصائيات وفلتر Spam
├── gui/index.html        # واجهة لوحة التحكم
├── controls.json         # إعدادات اللوحة (بتتولد تلقائيًا، مش بتترفع على Git)
├── data/                 # الذاكرة والإحصائيات (بتتولد تلقائيًا، مش بتترفع)
├── session/              # سيشن واتساب (بتتولد تلقائيًا، مش بتترفع)
└── .env                  # المفاتيح (اعملها نسخة من .env.example، مش بتترفع)
```

## 🚀 التشغيل السريع

1. **ثبّت المكتبات** (مطلوب Node.js 20 أو أحدث)

   ```bash
   npm install
   ```

2. **اعمل ملف `.env`** من القالب واملأ المفاتيح بتاعتك:

   ```bash
   copy .env.example .env     # على لينكس: cp .env.example .env
   ```

3. **ظبّط الشخصية** (اختياري) — عدّل `SYSTEM_PROMPT` في `config.js`.

4. **شغّل البوت**

   ```bash
   npm start
   ```

5. **امسح QR** (أول مرة بس): واتساب ← **الأجهزة المرتبطة** ← **ربط جهاز**.
   السيشن بتتحفظ في مجلد `session/` فمش هتحتاج تمسح تاني إلا لو عملت خروج.

## 🎛 لوحة التحكم (http://localhost:3750)

أي تغيير في اللوحة بيتحفظ في `controls.json` وبيتطبق فورًا من غير ما تعيد تشغيل البوت.

| القسم | وظيفته |
|---|---|
| التحكم الأساسي | تشغيل/إيقاف البوت، الرد على الجروبات/البرايفت، الرد الحر في الجروبات، تأخير الرد |
| إشعارات المالك | يبعتلك تنبيه على رقمك لما حد غريب يكلمك برايفت |
| فلتر Spam | حد أدنى لطول الرسالة + حظر الروابط |
| الأرقام المسموحة | الأرقام اللي البوت بيرد عليها في البرايفت |
| الردود السريعة | كلمة مفتاحية → رد جاهز (ونفس الكلمات بتستخدم كـ triggers في وضع "triggers") |
| الإحصائيات | إجمالي عدد الردود من آخر إعادة تعيين |

## 💬 الأوامر (من واتساب)

| الأمر | الوصف |
|---|---|
| `/clear` | مسح ذاكرة المحادثة معك |
| `/help` | عرض قائمة الأوامر |
| `/mode free` | الجروبات: الرد على أي رسالة |
| `/mode triggers` | الجروبات: الرد على الرسايل اللي فيها كلمة من الردود السريعة بس |

## ⚙️ الإعدادات

### متغيرات البيئة (`.env`)

| المتغير | الوصف |
|---|---|
| `GROQ_API_KEY` | مفتاح Groq — المزوّد الأساسي |
| `GEMINI_API_KEY` | مفتاح Google Gemini — المزوّد البديل |
| `MY_NUMBER` | اختياري: رقمك عشان تستقبل الإشعارات |
| `GUI_PORT` | اختياري: بورت لوحة التحكم (الافتراضي `3750`) |

### إعدادات البوت (`config.js`)

| الإعداد | الوصف |
|---|---|
| `SYSTEM_PROMPT` | شخصية البوت — خليها شبهك |
| `MODEL` / `MODEL_GEMINI` | موديل Groq / موديل Gemini البديل |
| `MAX_TOKENS`, `TEMPERATURE` | حدود التوليد ودرجة الإبداع |
| `MAX_HISTORY` | عدد الرسايل اللي البوت بيفتكرها لكل رقم |
| `MIN_TYPING_DELAY`, `MAX_TYPING_DELAY` | نطاق تأخير الكتابة (مللي ثانية) |

## 🐳 النشر

### Docker (الطريقة المفضلة)

```bash
docker compose up -d
docker compose logs -f whatsapp-bot   # بص على اللوجات عشان تلاقي الـ QR أول مرة
```

السيشن بتتحفظ في مجلد `./session` على الجهاز، فإعادة النشر مش محتاجة مسح QR من جديد.

### Fly.io

`fly deploy` — ملف `fly.toml` بيظبط volume دائم على `/app/session` بالفعل.

### Render

ملف `render.yaml` فيه Worker جاهز. حط `GROQ_API_KEY` و `GEMINI_API_KEY` من الداشبورد.

### PM2 (سيرفر عادي)

```bash
npm install -g pm2
pm2 start ecosystem.config.js
pm2 save
```
